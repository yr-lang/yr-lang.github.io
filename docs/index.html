><

Body

HTML inside the body. Place elements with _ .

>>

Head

Meta tags, links and fonts.

##

CSS

Regular CSS, injected as a style block.

@@

Frontend JS

JavaScript that runs in the browser.

&&

Backend JS

Node.js, compiled as app.js .

**

DevOps

Build, serve and deploy scripts.

><

Wrapper

A reusable component with a slot for children.

!!

Bring in another .yr file.

      Why AI writes Yr well
    

    

      Most projects are spread over dozens of files. Yr is built the other way around.
    

    

      

        

          The whole feature in one place
        

        

          Page, style, browser code, server code and deploy scripts sit in the same
          
            .yr
          
          file. The AI reads a complete feature at once instead of chasing imports across folders.
        

      

      

        

          Sections are clear boundaries
        

        

          Every section starts with a two-character marker. The AI finds the part to change, edits it, and leaves the rest of the file alone.
        

      

      

        

          Nothing new inside
        

        

          Inside each section it is plain HTML, CSS, JavaScript, Node or Bash, which every AI already knows. The only new thing is a short list of markers.

      Yrkit is written in Yr
    

    

      Yrkit is the app where you build systems by talking to an AI. You describe what you want in plain language, and it writes the whole project for you.
    

    

      It is written entirely in Yr. Building Yrkit is what pushed the language forward: wherever the project needed something the language could not do yet, the language grew. Today it is the largest project running on Yr, and it works in production.

      yr-cli
    

    

      yr-cli is the command line tool for Yr. It builds, serves and deploys your projects from the terminal.
    

    

      Install it globally with npm:
    

    
      npm install -g @yr-lang/yr-cli
